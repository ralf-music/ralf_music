Snikkers Run
Standalone-Version

Eigene Spielversion: derzeit nicht separat vergeben.
Quellstand: übernommen aus One More Day v0.9.20.

Dieses Paket läuft eigenständig und benötigt die One-More-Day-App nicht.
An Spielmechanik, Grafik, Musik und Layout wurde gegenüber dem Quellstand nichts verändert.
Der gemeinsame game-viewport.js-Helfer liegt lokal im Paket, damit Snikkers Run unabhängig portiert werden kann.

Start: index.html über einen lokalen Webserver oder Webhosting öffnen.
